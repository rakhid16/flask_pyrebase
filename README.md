# Make Firebase as Your Python Backend with Pyrebase

Contoh kode untuk webinar Surabaya.py pada Juni 2020.

## Panduan memulai

1. Clone repositori ini.

   ```bash
   git clone https://github.com/Rakhid16/flask_pyrebase.git
   ```

2. Masuk ke direktori repositori yang sudah diunduh.

   ```bash
   cd flask_pyrebase
   ```

3. Pasang dependensi.

   ```bash
   pip install -r requirements.txt
   ```

4. Masuk ke salah satu folder contoh.

   ```bash
   cd database
   ```

   atau

   ```bash
   cd storage
   ```
